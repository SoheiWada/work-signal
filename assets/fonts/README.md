# Noto Sans JP

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp

`NotoSansJP.ttf` is the unmodified variable font distributed upstream as
`NotoSansJP[wght].ttf`. It is used to render Japanese text in the generated
social preview images. The accompanying SIL Open Font License is in `OFL.txt`.
The font itself is not included in the deployed website output.
