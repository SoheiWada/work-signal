## デザイン

コンセプトは静かなアリーナ。生成り、墨色、WORK SIGNALのオレンジ。大きな文字と細い罫線の緊張感、遠近のあるコート面と静かなシグナル、余白で奥行きを作ります。

- ヒーロー: ローカルのAntonフォント、CSSとSVGで描いたコートのみ。ボール・外周の軌道線・NBAとチームの公式ロゴは使用しません。マウスでごく小さく視点が変わります。
- コートの演出: 架空の選手軌跡を表す10個のシグナル（5対5）が同じコート面を移動。28秒の振付を滑らかにループし、十字と小さな菱形が移動し、9秒周期の細い走査線がその位置を捉えると、角形の受信パルスがその場に広がって消えます。走査後には休止を入れ、常時点滅はさせません。丸い点と連続した尾は使いません。実際の選手追跡データではありません。30fpsを上限に更新し、画面外・非表示タブ・一時停止時は描画を止めます。reduced-motionは静止表示。コート下の操作で静止・再開できます。
- 試合結果: 大きなスコアを並べる黒い紙面。ホバーでオレンジへ切り替わり、選択すると受信表示から詳細が開きます。
- 参考順位: EAST/WEST、上位6チームと全15チームの切り替え。同勝率は同順位。
- スマートフォン: 文字の組み方と余白を変更。コートは独立した空間として残し、表は得点ではなく勝敗・勝率を読みやすく配置。
- キーボードで操作可能。ネイティブdialogでフォーカスを管理し、Esc、閉じる、背景クリックで終了。受信中のEscも中止可能。reduced-motionではシグナルの移動・視点追従・拡大・フェードを停止し、操作は維持。

外部フォント、写真、チームロゴ、分析スクリプト、外部JavaScript、API呼出しは使いません。AntonはSIL Open Font Licenseで配布されるGoogle Fontsのフォントをローカル同梱。原本とライセンスは`../../nba/fonts/`。出典: https://github.com/google/fonts/tree/main/ofl/anton

## 数値について

**すべてのスコア・勝敗・参考順位は架空のデザイン用データです。** 選手の有料統計、オッズ、実際のライブ結果は含めません。先頭と各データ領域、詳細、フッターに明記。日程・成績の実データ接続は未実施です。

参考順位は勝率の独自ソートで、同率は同順位とします。公式シード、プレーオフ境界、タイブレークを表現しません。表示中の順位表は直下の12試合から計算したものではなく、別の架空シーズン成績です。

実際に接続するには無料アカウントとAPIキーが必要です。キーはサーバー側だけに置き、このページへ渡しません。共有キャッシュ・日次更新・停止条件・リクエスト上限を設定し、自動で有料へ移行しない構成が必要です。過去試合の完全な取得、シーズン区分、延期・中止・カップ決勝等の扱いを検証してから勝敗・勝率の独自集計を接続します。欠損する期間を完全なシーズン成績として出しません。

本番ではサーバーの無料枠と過剰アクセス時の停止設定も確認。費用を避けるため、更新頻度は日次・試合終了後中心を予定し、リアルタイム更新は約束しません。
