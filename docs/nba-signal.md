# NBA SIGNAL — 実装と公開境界

2026-10-21。承認されたコートのシグナル演出を`nba/`へ組み込みました。2026-10-21にユーザーから本番公開承認を受領しました。実データ未接続の表示で公開する対象です。

## 実装

- `nba/court-motion.mjs`: 5対5の架空の動き、9秒周期の走査（7.5秒走査＋1.5秒休止）、検知した場所から1.6秒で消える角形の受信パルス。尾は使いません。
- `nba/page.mjs`: 試合詳細、受信表示、キーボードとフォーカス、結果・参考順位、未取得表示の共通実装。
- `nba/app.mjs`: 通常表示の入口。実データは未接続。架空データへのフォールバック・外部APIの呼出し・キーの保持はありません。
- `nba/style.css`と`nba/index.html`: 採用したタイポグラフィ、余白、コート、モバイル配置。NBA・チームのロゴは使用しません。
- 動きは30fps上限。画面外・非表示タブ・一時停止・ページ離脱で停止。reduced-motionでは走査と受信パルスを含め静止します。

## ビルドと費用

`build_site.py`は`nba/`のHTML・CSS・4つのJS module・フォント・ライセンスの8ファイルだけをコピーします。既存のGitHub Pages方式を継続し、新しいサービス・有料API・トライアル・アカウントは作っていません。NBAのAPIキーもまだ設定していません。

トップLP、既存W、記事は今回変更していません。ホームへのNBAリンクは追加せず、実データ接続までNBAページをnoindexにし、サイトマップにも追加しません。

実際の試合結果・成績の公開には、無料データ源の最新利用条件、無料キー、共有キャッシュ、上限での停止、全試合の欠損検証が残ります。[調査時の条件と接続の前提](../prototypes/nba-signal/README.md#費用0円の条件)を参照し、接続時に再確認してください。演出は実際の選手追跡データとは連動しません。
