## 標準構成

```
GitHub PagesのWヒーロー
  → 表示中のみ5分間隔
  → Gold API（BTC / ETH / XAU）＋Frankfurter（USD→JPYブレンド日次参考値）
  → ブラウザーの5分キャッシュと最大50時間の実観測
```

無料・キー不要の価格エンドポイントだけを使います。ブラウザーにAPIキーはなく、新しいサーバー契約も不要です。[公式条件と取得基準](free-market-data.md)を参照してください。

`assets/js/free-market-feeds.mjs`は価格・単位・銘柄・時刻・比較元を検証する共通アダプター。`free-market-client.mjs`がブラウザーのキャッシュと取得間隔を管理します。サーバー側アダプターも同じ検証コードを参照します。公開ビルドにはサーバーコード・設定例・テスト・架空データを含めません。

同じブラウザーの同じオリジンではlocalStorageにスナップショットと最大50時間（1銘柄610観測）の履歴を保存。Web Locks対応時はタブ間の取得も排他。保存不可でもメモリーで動きます。Gold APIの3リクエストは開始を約1.15秒ずつずらし、失敗時も5分間隔で再試行。取得確認時刻をキャッシュ読取りだけで更新しません。閲覧者のブラウザーごとの取得であり、全訪問者に共通のサーバーキャッシュではありません。

## デザインと操作

承認されたWの要素・サイズ・色・28秒回転は維持。市場の数字だけが背景なし・通貨記号なしで浮遊・回転します。PCは最大4つ、400〜700pxは3つ、399px以下は2つ。12秒ごとに入れ替えます。

数字へのマウス滞在・タップ・キーボードで、目視できる受信パルス→小さな詳細カードを表示。対象の数字だけをロックし、別の数字の回転は止めません。静止設定・指標選択はカード内に集約しています。44px以上の操作領域、フォーカス復帰、Escで終了、reduced-motionに対応。画面外・非表示タブでは取得を止めます。

記事・記事カード・他のLPの要素・NBAページは今回変更していません。ヒーロー外に操作列を追加しません。

## 数値の扱い

- BTC / ETH / GOLD: 提供元参考値。取引状態と遅延は未確認と明記。GOLDはUSD/OZで、LBMA公式価格とは扱いません。
- 変動率: 同じフィードの約24時間前（±15分）の実観測がある場合だけ計算。表示していない間は収集しないため、比較元がなければ「算出準備中」。0%を補いません。
- USD/JPY: 日次参考値。基準日は日付だけ。前回公表値と比較し、比較日を表示。取引レート・終値と呼びません。
- 取得確認15分超、Gold APIの価格時刻15分超、FXの基準日7日超は浮遊表示から除外。失敗で価格・取得時刻を繰り上げません。
- 詳細に価格・単位・変動率の定義・価格更新時刻または基準日・取得確認・配信条件・出典を表示。すべての提供元文字列はtextContentで扱います。

## 設定と無効化

`index.html`の`work-signal-market-mode=free`と空の`work-signal-market-endpoint`が標準です。GitHub Pagesの既存ビルドだけで動作し、Workerの作成は不要です。

無効化する場合はmodeを`off`へ変更。承認済みの共有配信先へ切り替える場合だけendpointにHTTPS URLを設定します。endpoint指定がある場合はそちらを優先し、失敗しても別フィードへ自動で切り替えません。不正なendpointでも直接取得へはフォールバックしません。

`services/market-data/worker.mjs`とWrangler設定は任意の共有配信方式として保持。既定は無効で、今回作成・デプロイしません。有料Twelve Data・指数の設定やAPIキーも使いません。
